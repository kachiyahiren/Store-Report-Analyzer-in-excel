# 🏪 Store Sales Report Dashboard (Excel)

## 🚀 Project Overview
This project is an interactive **Excel dashboard** designed to analyze store sales performance across different regions and product categories.

It transforms raw sales data into meaningful insights using pivot tables, charts, and slicers, enabling quick business decision-making.

---

## 🎯 Objectives
- Analyze total sales across regions
- Evaluate product category performance
- Compare average sales across regions and categories
- Enable dynamic filtering using slicers

---

## 📁 Project File
- `Analyzer.xlsx` → Contains raw data, pivot tables, and dashboard

---

## 📊 Dashboard Features

### 📌 1. Total Sales vs Region
- Displays sales distribution across:
  - Central
  - East
  - North
  - South
  - West

👉 Insight:
- **West and Central regions** generate the highest sales
- **East region** shows the lowest performance

---

### 📌 2. Total Sales vs Product Category
- Categories:
  - Books
  - Clothing
  - Electronics
  - Furniture
  - Office Supplies

👉 Insight:
- **Books and Clothing** contribute the highest revenue
- **Office Supplies** has the lowest contribution

---

### 📌 3. Average Sales: Category vs Region
- Multi-line comparison across regions

👉 Insight:
- **Furniture dominates across all regions**
- Sales spike significantly in Furniture category
- Other categories show relatively low and stable trends

---

### 🎛 Interactive Filters (Slicers)
- Region filter
- Product Category filter
- Sales value filter

👉 Allows dynamic exploration of data

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers for interactivity
- Basic data aggregation

---

## ⚙️ Data Analysis Approach
1. Cleaned and structured raw dataset
2. Created pivot tables for:
   - Region-wise sales
   - Category-wise sales
3. Built charts for visualization
4. Added slicers for interactivity

---

## 📌 Key Insights
- Sales are **regionally concentrated** in West and Central
- Furniture category is a **major revenue driver**
- Sales distribution is **uneven across categories**
- Some regions underperform consistently → potential growth areas
